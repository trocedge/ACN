## 1. 用哪份名单，为什么

学长意见里说的「教育部白名单竞赛」，落到高校场景有两份容易混淆的文件，必须分清：

| 名单 | 覆盖对象 | 本项目是否采用 |
|---|---|---|
| 教育部《2025—2028 学年面向中小学生的全国性竞赛活动名单》，47 项 | **中小学生**（小学 / 初中 / 高中 / 中专） | ❌ 不采用，学段不符 |
| 中国高等教育学会《2024 全国普通高校大学生竞赛分析报告》竞赛目录，84 项 | **普通高校大学生**（本科 / 高职） | ✅ **采用** |

采用理由：本项目面向高校学生，第二份是国内高校普遍认可并用于保研加分、学科竞赛统计的竞赛目录，高校教务处、研究生院公开发布的通知均引用此目录。

> 若项目组的真实定位是服务中小学生赛事，请改用第一份 47 项名单，本文件与 `competition/whitelist.yml` 需整体替换。**这个定位请项目组拍板，不擅自切换。**

## 5. 报名截止日期为什么是空的

这是当前最大的缺口，原因说清楚：

- 84 项竞赛的当期（2026—2027 赛季）报名截止时间，需要逐项到各自官网核对，且多数赛事尚未发布下赛季通知
- 没有核实过的时间**一律不填**。填错日期比空着更糟——用户按错的时间准备，直接误事
- 采集方式：每核实一条，在 `whitelist.yml` 对应条目下补 `season` 与 `deadline` 字段，并在 PR 里附官网截图或链接

## 6. 收录标准

一条竞赛要进主线，须同时满足：

1. 出现在上述 84 项官方目录中，序号可对上
2. 竞赛名称与官方目录原文一致，不改写、不简化
3. 有可核验的官网链接（未核实则 `site` 留空，不允许填猜测地址）
4. 数据文件的 `sub` 取值必须在 `competition/types.yml` 的 12 个短码之内
