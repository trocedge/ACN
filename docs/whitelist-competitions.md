# 教育部白名单竞赛清单

> **状态：未填真实名单（未做）。** 本文件只提供收录标准与表格骨架，不编造任何竞赛名称、主办方或链接。
> 名单来源须由项目组提供教育部官方公示材料后填入，填入前本清单不可作为收录判定依据。

## 1. 收录标准

一条竞赛要进主线，须同时满足：

1. 出现在教育部公布的《面向中小学生的全国性竞赛活动名单》中（官方公示为准，不采信二手转载）
2. 有明确的主办方、面向学段（小学 / 初中 / 高中 / 中专）
3. 有可核验的官方报名或赛事链接
4. 有明确的报名截止日或比赛时间节点

## 3. 数据来源登记

每填一条，在「数据来源」列写清官方公示的具体出处（公示文件名 + 发布单位 + 日期），便于他人复核，避免以讹传讹。

## 4. 与数据的关联

- 竞赛类数据的分类值用 `competition`，与历史 `conference` 会议数据区分
- 一条竞赛数据应能对应到本清单中的一行（靠名称 + 主办方匹配）
- 具体字段定义见 `docs/field-contract.md`
